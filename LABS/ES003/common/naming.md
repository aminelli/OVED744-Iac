# Convenzioni di naming

- Resource Group: rg-app-<environment>
- Virtual Network: vnet-app-<environment>
- Subnet: snet-app-<environment>
- Network Security Group: nsg-app-<environment>
- Public IP: pip-app-<environment>
- Network Interface: nic-app-<environment>
- Virtual Machine: vm-app-<environment>

Ambienti ammessi:
- dev
- test
- prod

Tutte le risorse devono avere nomi coerenti con
l'ambiente e il progetto.
